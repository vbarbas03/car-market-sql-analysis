Car Market Price Analysis using SQL

This project analyzes over 550,000 car auction sales records using MySQL.
Raw CSV data was imported via command line, cleaned, and transformed into
an analysis-ready dataset to explore pricing trends and depreciation.

Tools
- MySQL
- Command Line (CMD)

Key Steps
- Imported raw Kaggle CSV data (558k+ rows)
- Cleaned non-standard datetime formats with SQL
- Converted numeric fields safely
- Built analysis-ready tables

Analyses
- Average selling price by brand
- Market vs selling price (MMR gap)
- Mileage-based depreciation
- Monthly price trends
- Most sold car brands
